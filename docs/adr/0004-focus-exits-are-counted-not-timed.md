# Focus exits are counted, never timed, and never evidence

The 30-minute focused sitting is a product choice with no rule behind it. Leaving the screen during a sitting is therefore recorded only as a `FOCUS_EXIT` event and a count per sitting: no seconds away and no destination. It is never shown to a reviewer as evidence or used in a decision. On desktop only a hidden page counts as an exit; closing full screen does not. Touch devices get no full screen and no exit warnings. We chose this over the first build's "time away" logging (RF-05) because behavioural monitoring without a stated purpose fails DPDP purpose limitation. We chose it over enforcing full screen because iPhone Safari, in-app browsers, the phone camera and screen readers all cause false exits (RF-20).
