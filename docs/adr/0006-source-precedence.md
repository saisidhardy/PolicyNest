# Which source wins when the documents disagree

For decision logic, the brief's guardrails and the rulebook v3.2 win. For product choices, the user's standing decisions win (CLAUDE.md and the Phase 3 decisions). The `07_WORKFLOW_AND_BUSINESS_LOGIC` specifications, the data dictionary and the research reports are advice. The order is recorded because the specs contradict the rulebook in places: suppressing reasons for ineligible applicants, a human-review band for age, locked documents, different message wording (RF-62 to RF-65). Without it, a future reader of the code could "fix" rulebook behaviour back to a spec.
