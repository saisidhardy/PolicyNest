# The PAN card's read values are the anchor; typed details are only compared

Every cross-document check compares against the name and date of birth read from the PAN card, not against what the applicant typed. Typed values are compared and reported as information only; a one-character PAN typing error is corrected from the card and logged (rulebook §4.2). This follows rulebook §3 ("the anchor document") and the brief's observation that typing errors are common and never checked. A reader might expect the form to be the source of truth. It deliberately is not, because a decision built on typed values would approve whatever the applicant claims.
